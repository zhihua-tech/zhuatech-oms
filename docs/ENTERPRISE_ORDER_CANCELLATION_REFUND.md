版权所有 © 2026 上海如静知华信息科技有限公司（[知华科技官网](https://www.zhuatech.cn/)）。

## 业务闭环

取消申请 → 政策校验 → 发运拦截 → 库存释放 → 原支付与金额核对 → 权益及税务回退 → 欺诈复核 → 审批退款 → 渠道/客户通知 → 到账监控。

## 退款门禁

- 取消必须符合渠道政策，已下发履约的订单必须先完成仓库和承运拦截。
- 库存占用、优惠券、积分和促销权益必须准确回滚。
- 退款必须关联原支付交易，金额与实付对平，发票和税务处理完成。
- 欺诈复核、必要的客户身份核验、财务和业务批准必须通过。
- 经办与审批职责必须分离，订单到退款全链路证据必须完整。

## 接口与决策

`POST /api/enterprise/oms/order-cancellation-refund`

返回 `REFUND`、`REVIEW` 或 `BLOCKED`。渠道、仓储、支付和税控系统仅预留标准适配方式，由部署方自行配置。
