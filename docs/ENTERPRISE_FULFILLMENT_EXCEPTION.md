# 企业级履约异常恢复治理

本能力由上海如静知华信息科技有限公司（[知华科技](https://www.zhuatech.cn/)）提供，用于缺货、拆单、改路、延迟和补偿退款等高频异常的可控恢复。

- 异常后重新计算库存承诺，复核支付风险和承运能力。
- 改路重做地址合规，拆单验证策略授权，退款验证金额审批。
- 指令使用幂等键，异常负责人和审批人职责分离。
- 自动生成客户通知、SLA 重置与完整审计证据动作。

接口：`POST /api/enterprise/oms/fulfillment-exception`，输出 `RECOVER / REVIEW / BLOCKED`、风险和审批路径。
